
# LYFE CHECK | Project Showcase

## About the Project

LYFE CHECK is my Computer Science thesis project, focused on bringing personal wellness and productivity together in one application. My goal is to create a platform that helps users stay organized, build healthy routines, and make time for self-reflection.

LYFE CHECK originally started as a Java and JavaFX desktop application for my Object-Oriented Programming class. Since then, I have continued developing the project into a web application using React, TypeScript, and a cloud-based backend.

This showcase website highlights LYFE CHECK's features, design process, and development journey.

## Website Features

- **Project Overview:** Introduces LYFE CHECK and explains the motivation behind the project.
- **Feature Explorer:** Allows visitors to search and filter LYFE CHECK's features.
- **Development Journey:** Explains how the project evolved from a desktop application into a web application.
- **Prototype Gallery:** Displays screenshots of the LYFE CHECK Figma prototype.
- **Feature Recommendation Quiz:** Suggests LYFE CHECK features based on a visitor's selected challenge.
- **Dark Mode:** Allows visitors to switch between light and dark themes.
- **Responsive Design:** Adjusts the website layout for desktop and mobile screens.

## Technologies Used

This showcase website was built using:
